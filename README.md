# amber-accrete

Kept plans: a model writes an agent plan once, amber freezes it after setup, and accrete keeps the frozen bytes. Each new task forks from the kept snapshot instead of starting again.

This package joins two independent projects:

- [amber](../amber) freezes and resumes running programs. It does not know about accrete.
- [accrete](../accrete) keeps checked code and stores bytes by hash. It does not know about amber.

Only this package imports both. `npm run gate` fails if amber or accrete imports the other.

## API

```ts
import { keepFrozen, forkKept } from "amber-accrete";

const key = await keepFrozen(client, script, engineSha, ["diff-checklist"]);
const { script: fork, token } = await forkKept(client, key, { ...scriptOptions, engineSha, maxAgeMs: 3_600_000 });
await fork.answer(token, nextDiff);
```

`forkKept` refuses to resume when:

| Refusal | When |
|---|---|
| `EngineChanged` | The snapshot was frozen on a different `dq.wasm` |
| `SnapshotTooOld` | The snapshot is older than `maxAgeMs` |
| `ToolChanged` | A kept tool the plan depends on has a new hash in accrete |
| `WritesRefused` | The fork has a write tool and `allowWrites` is not set |

## Eval: A/B/C

Receipt: `bench/abc.json`. Kimi K2.6 wrote one plan of 313 characters, not edited. The same 10 diffs go through each arm. Setup is real: the model reads the cloudflare-agent `packages/analytics` contributor rules, and tsc runs on that package through accrete.

| Arm | What runs | Correct | Model tokens | Total time | Median per diff |
|---|---|---|---|---|---|
| A: amber alone | Plan from the top each time. The model writes each checklist. | 7/10 | 23911 | 172572 ms | 16918 ms |
| B: accrete alone | Plan from the top each time. The checklist is a kept accrete tool. | 10/10 | 22699 | 158005 ms | 16162 ms |
| C: both | Plan frozen once after setup and kept in accrete. Each diff forks from it. | 10/10 | 2275 | 28954 ms | 760 ms |

The C totals include the one freeze: 21504 ms and 2275 tokens. After the freeze, the 10 forks used 0 model tokens.

What the numbers show:

- Kept tools fix correctness. In A the model miscounted lines on 3 of 10 diffs. The kept tool was correct every time.
- Kept snapshots fix cost. B still pays setup on every diff. C pays it once, so it uses about 10 times fewer tokens than A.
- Neither part alone gets both.

## Not proven

- The diffs are synthetic, small and generated by the eval. Real merge requests are larger and less regular.
- The decision step is a fixed rule, not a model call. Every arm skips the same work, so the comparison is fair, but real decision cost is not measured.
- 10 diffs and one plan. There is no variance across plans or models yet.
- The age limit is a fixed number. There is no rule yet for which facts in a frozen plan go stale.
- All container-seconds were 0 because accrete already kept tsc and the checklist tool. A cold registry adds a one-time build to every arm.
